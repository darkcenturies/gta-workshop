# Contributing

Start with [GTA Workshop](README.md), [the documentation index](docs/README.md)
and [Dryxio references](research/dryxio-catalog.md). Choose visibility and the
implementation owner before writing a request, source, log or attachment.

Contribute mod-making guides, reference corrections, research findings,
generated evidence, workflow maps and safe project summaries here.
Mod/tool source, build recipes, experimental adapters and releases belong in
their implementation owner.

1. Use a branch/fork for one clear knowledge contribution.
2. Record target/version, revision, method, evidence and limits.
3. Review local links, catalog/graph consistency, public scope and archive hashes.
4. Commit/push and open a PR describing actual checks and remaining questions.

Every task originating here returns committed public-safe findings, including
work implemented elsewhere and useful negative results. Use
[the finding template](research/finding-template.md). Keep full restricted
evidence in the private owner and explain withholding safely.

No player data, credentials, production configuration, private history, executable
inputs or game payloads. Retain original attribution and per-record rights.
Generated research is evidence, not original vendor source or automatically BSD
licensed implementation. Read [PUBLICATION.md](PUBLICATION.md) and
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Review is required for normal contributions. Merging documentation does not
publish a binary, install mods or deploy services.
