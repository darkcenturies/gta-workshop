# Valkyrie Repair for GTA San Andreas

Read-only scanning with individually approved repairs and integrity-checked
Undo. Close the game before applying changes. Repair builds and embeds the
fresh combined Doctor & Crashfix ASI; it offers one installation/update and
optional retirement of older standalone Crashfix copies. Unknown or newer
Doctor builds are preserved. It supplies no game assets.

Build: `src/build.ps1`. The build runs isolated self-tests without repairing
a real installation. Third-party CrashInfo notices and combined-ASl source
distribution terms remain applicable. Gameplay validation is pending.
