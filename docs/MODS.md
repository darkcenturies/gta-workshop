# Valkyrie mod guide and ownership

This is an information catalog. Mod source, builds and releases are held in
their implementation owners, not GTA Workshop.

| Component | Owner | Important boundary |
| --- | --- | --- |
| Doctor + Crashfix | Private Valkyrie Workshop | One artwork-free x86 ASI; preserve guard GPL and diagnostic-resource notices |
| Map | Private Valkyrie Workshop | Historical public snapshot was 0.2.0; exact source for the later 0.2.1-test download remains unresolved |
| Repair | Private Valkyrie Workshop | C# utility; current build embeds combined Doctor/Crashfix, with old independent payloads retired |
| Winmode Nullfix | Historical research record | Standalone corresponding source has not been located |
| Phone | Public valkyrie-phone | Independently buildable reviewed scope; maps and optional browser content have separate input requirements |
| Core, Atmosphere, Fuel, Radar and other native mods | Private Valkyrie Workshop | Catalog inclusion does not approve source exports |

Use [the complete component catalog](workshop/CATALOG.md), [build-method guide](BUILDING.md)
and [GTA SA workflow](GTA-SA-MOD-WORKFLOW.md). Current maintained mods target
classic GTA SA; historical partner compatibility is evidence to recheck, not
current affiliation. Other permitted artwork remains allowed.

Compilation and isolated tests do not establish game behavior. Report exact
targets, signature evidence, gameplay checks and unresolved source gaps.
Player-facing downloads are separate from source visibility and this knowledge
repository. Follow the owning release process and [publication policy](../PUBLICATION.md).
