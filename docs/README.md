# Documentation

[GTA Workshop](../README.md) is a public reference library for GTA mod-making.
Choose a task or research question rather than a developer's product.

Guides explain methods. Reference inventories record revisions, attribution and
evaluation status. Evidence records exact targets, provenance and limitations.
Dated historical project notes are evidence, not the library's organizing model
or current install instructions. Keep catalog and maps consistent; every task
returns safe findings. Archive metadata and checksums stay byte-exact.
